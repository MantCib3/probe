Maintaining a 707-Definition Source Catalog

Coverage is not the number of URLs in a file. It is the number of sources that still produce useful evidence.

19 September 20265 min read

Username catalogs age quickly. Platforms close, profile routes change, APIs disappear, and formerly public pages become login-only. Keeping every historical definition active makes a scanner look larger while making its results worse.

Three source states

PROBE currently uses 324 automatic sources and 49 manual-only sources. Automatic sources have enough observable evidence for classification. Manual-only sources remain useful links, but their unauthenticated responses do not safely distinguish existing and absent users. Defunct definitions stay in the historical catalog but are not loaded by production.

Calibration over assumptions

Each automatic source should have a known-positive control and deterministic negative controls. A source is fully verified only when it handles its available positive and both negatives without abstaining. The current campaign fully verified 177 of 324 automatic sources.

Known-positive data also ages. Manual review found controls for accounts that had been deleted or renamed. A failing control is therefore an investigation prompt, not automatic proof that production logic is broken.

Maintenance is a product feature

The next operational step is scheduled source-health monitoring: detect route changes, marker drift, unusual status-code shifts, and sustained abstention increases before users report them. Community suggestions can expand coverage, but new sources should pass the same positive-and-negative evidence standard before entering automatic scans.
