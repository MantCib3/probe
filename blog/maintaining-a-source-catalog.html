Keeping sources current

Maintaining 322 Active Sources

A source count only matters when every included link remains useful.

19 September 20265 min read · updated 3 October 2026

Lists of username sites go out of date quickly. Platforms close, profile addresses change, APIs disappear, and public pages move behind login screens. Keeping every old entry would make PROBE look bigger while making its results less useful.

Two kinds of source

PROBE currently has 265 automatic sources and 57 that must be opened manually, for 322 functional sources in total. We removed 44 sources that were consistently blocked from the production server, while retaining 42 blocked sources for targeted proxy testing. Automatic sources give us enough information to make a useful decision. Manual-only sources remain useful links, but without logging in we cannot reliably tell whether a username exists.

Test, do not assume

We test each automatic source with an account known to exist and unusual usernames expected not to exist. A source is fully verified only when it handles the available real account and both missing accounts without returning an unclear answer. The 3 October campaign ran before the catalog was trimmed. Recalculating that run for today's retained sources, 190 of 265 automatic sources were fully verified; accuracy among clear decisions was 98.90%, coverage was 82.12%, and there were zero observed false positives. This is a re-analysis of the existing run, not a fresh campaign against the trimmed set.

The test accounts also need maintenance. During manual review, we found accounts that had been deleted or renamed. A failed test therefore tells us to investigate; it does not automatically mean PROBE is broken.

Keeping the list useful

The next step is to run these checks on a schedule and flag changes in profile addresses, page wording, response codes, or the number of unclear results. Suggestions from users can help expand coverage, but every new source should pass the same real-and-missing account tests before it is added to automatic scans.
