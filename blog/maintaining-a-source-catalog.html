Keeping sources current

Maintaining 373 Active Sources

A source count only matters when every included link remains useful.

19 September 20265 min read

Lists of username sites go out of date quickly. Platforms close, profile addresses change, APIs disappear, and public pages move behind login screens. Keeping every old entry would make PROBE look bigger while making its results less useful.

Two kinds of source

PROBE currently has 324 automatic sources and 49 that must be opened manually, for 373 functional sources in total. Automatic sources give us enough information to make a useful decision. Manual-only sources remain useful links, but without logging in we cannot reliably tell whether a username exists.

Test, do not assume

We test each automatic source with an account known to exist and unusual usernames expected not to exist. A source is fully verified only when it handles the available real account and both missing accounts without returning an unclear answer. The latest test fully verified 177 of 324 automatic sources.

The test accounts also need maintenance. During manual review, we found accounts that had been deleted or renamed. A failed test therefore tells us to investigate; it does not automatically mean PROBE is broken.

Keeping the list useful

The next step is to run these checks on a schedule and flag changes in profile addresses, page wording, response codes, or the number of unclear results. Suggestions from users can help expand coverage, but every new source should pass the same real-and-missing account tests before it is added to automatic scans.
