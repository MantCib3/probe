Regeneration
  npm run social:render
Requires the existing local Playwright module and its installed Chromium.
Playwright 1.60.0 (the version used here) is declared as a development dependency.
On a clean checkout, install the project dependencies and use
  npx playwright install chromium
if the local browser is not already available.
No source websites are visited: the renderer uses static inline HTML and blocks
all network requests. Browser work files stay under .social-render-work in the
project and are removed after rendering. No proxy or source-probing work is run.
