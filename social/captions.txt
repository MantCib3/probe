THE SOFT 404 EPIDEMIC
Image: the-soft-404-epidemic.png

Modern single-page applications return an HTTP 200 and a generic JavaScript shell whether a username exists or not. A naive scanner looking only at status codes finds phantom profiles on every SPA platform.
