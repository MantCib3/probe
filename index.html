How It Works

PROBE makes concurrent HTTP requests to each platform in parallel, checking profile URLs and analysing responses to determine whether a username is registered. Results stream live as they arrive.

01

Enter Username

Type any handle, alias, or username. PROBE accepts letters, numbers, dots, hyphens, and underscores.

02

Parallel Scan

All platforms are checked concurrently with a 10-second timeout per site for fast results.

03

Live Results

Results stream in real-time as each platform responds. Found profiles are highlighted immediately.

04

Export & Analyse

Download found profiles as a CSV, copy all URLs to clipboard, or open each profile directly in a new tab.

Accuracy note: "Found" means the platform URL returned a successful response — verify manually before drawing conclusions.
